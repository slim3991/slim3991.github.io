Selected Projects & Code

Incremental SVD Library

C++17 / Eigen / pybind11 / NumPy / CMake

Implemented Brand’s Incremental Singular Value Decomposition algorithm in modern C++ with a Python interface. Designed for low-rank approximation of streaming data without recomputing full SVDs from scratch.

  • Supports rank truncation and exponential forgetting factors for dynamic streaming data.
  • Features precision flexibility (float32 / float64) and seamless Python bindings via pybind11.
View Repository on GitHub

Parallel Preconditioned Conjugate Gradient Solver

C++17 / OpenMP

A C++ implementation of a parallel Preconditioned Conjugate Gradient (PCG) iterative solver designed for large sparse linear systems.

  • Custom Compressed Sparse Row (CSR) matrix representation optimized for continuous memory access.
  • Parallelized sparse matrix-vector multiplication (SpMV) kernels and vector dot products using OpenMP.
  • Includes Jacobi preconditioning to accelerate convergence on ill-conditioned systems.
